# AR/VR — Extended Reality Resource & Learning Project

## 📌 About the Project

This project is a structured learning and research resource focused on **Extended Reality (XR)** technologies.

Extended Reality is an umbrella term that includes:

- **Augmented Reality (AR)**
- **Virtual Reality (VR)**
- **Mixed Reality (MR)**

The purpose of this project is to organize important XR concepts, learning resources, development tools, devices, applications, and industry information in one place.

## 🎯 Objectives

- Understand the fundamentals of AR, VR, and MR.
- Explore the evolution and applications of Extended Reality.
- Learn about XR development and design resources.
- Explore commonly used XR hardware and platforms.
- Collect useful learning materials for students and developers.
- Understand current applications and trends in immersive technologies.
